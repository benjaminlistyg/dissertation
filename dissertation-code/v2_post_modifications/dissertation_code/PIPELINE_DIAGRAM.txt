  CROSS-WAVE REPLICABILITY  (OSC, 2015)
  ──────────────────────────────────────

  For all 20 model pairs (M2 vs M3), extracts EF-related coefficients:
  - Pairs each M2 model with its M3 counterpart
  - Computes 3-step OSC criteria:
      Step 1: Same sign (of W1-significant effects)
      Step 2: Same sign AND significant in both waves
      Step 3: Overlapping 95% CIs (among effects sig in both)

  OUTPUT: reg_replicability (paired dataframe, 20+ rows)

  4-FACTOR CORRELATED CFA MODEL
  ─────────────────────────────

  ┌───────────────────────────────────────────────────────────────────────┐
  │                                                                       │
  │  MIDUS 2 Items                        MIDUS 3 Items                   │
  │  ─────────────                        ─────────────                   │
  │  neg_wtf =~ B1SF27A+B+C+D            neg_wtf =~ C1SF40A+B+C+D       │
  │  pos_wtf =~ B1SF27E+F+G+H            pos_wtf =~ C1SF40E+F+G+H       │
  │  neg_ftw =~ B1SF27I+J+K+L            neg_ftw =~ C1SF40I+J+K+L       │
  │  pos_ftw =~ B1SF27M+N+O+P            pos_ftw =~ C1SF40M+N+O+P       │
  │                                                                       │
  │  4 factors × 4 items each = 16 items per wave                        │
  │  Factors freely correlated.  std.lv = TRUE.                           │
  │                                                                       │
  └───────────────────────────────────────────────────────────────────────┘

  ANALYSES RUN
  ────────────

  1. CFA (lavaan::cfa)
     • fit_m2 ← cfa(model, data = df_m2_analytic)
     • fit_m3 ← cfa(model, data = df_m3_analytic)
     → Reports: chi-sq, df, p, CFI, TLI, RMSEA [90% CI], SRMR
     → Reports: Standardized loadings, Factor correlations

  2. Measurement Invariance across Gender (B1PRSEX / C1PRSEX)
     • inv_m2 / inv_m3 ← sequence of 4 nested models:

     ┌──────────────────────────────────────────────────────────┐
     │  Level          │  Constraint                            │
     │─────────────────┼────────────────────────────────────────│
     │  Configural     │  Same factor structure across groups   │
     │  Metric         │  + Equal factor loadings               │
     │  Scalar         │  + Equal intercepts                    │
     │  Strict         │  + Equal residual variances            │
     └──────────────────────────────────────────────────────────┘

     Decision: ΔCFI < .01 between levels → invariance supported (Chen, 2007)

  HTML TABLES (generated in-script to output/tables/cfa/):
  • cfa_fit_indices.html         (M2 and M3 fit indices)
  • cfa_loadings_m2.html         (standardized loadings M2)
  • cfa_loadings_m3.html         (standardized loadings M3)
  • cfa_factor_correlations_m2.html
  • cfa_factor_correlations_m3.html
  • invariance_gender_m2.html    (MI table M2)
  • invariance_gender_m3.html    (MI table M3)
